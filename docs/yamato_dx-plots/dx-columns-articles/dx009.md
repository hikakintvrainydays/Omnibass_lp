# デジタルガバナンス・コード3.0が中小企業に与える影響

経済産業省は「デジタルガバナンス・コード」を改訂しながら、企業のDX推進に必要な経営の在り方・指針を示してきました。2024年に公表された3.0版では、SX(サステナビリティ・トランスフォーメーション)やGX(グリーン・トランスフォーメーション)、人的資本との接続が明確化され、企業のDXに対する社会的期待が一段引き上げられています。本稿ではコード3.0の改訂ポイントと、中小企業に求められる現実的な対応範囲を整理します。

## デジタルガバナンス・コードの位置づけ

デジタルガバナンス・コードは、情報処理促進法に基づき経済産業大臣が定める指針です。DX認定制度の判定基準とも整合しており、「企業がDXを推進するうえで経営者に求められる事項」を示しています。法的義務を直接課すものではありませんが、DX認定を取得する企業はこのコードに対応する必要があります。

つまり、上場・非上場、規模を問わず、**国としてのDX推進の標準フレーム**として機能している点がポイントです。

## コード3.0で何が変わったか

3.0版では主に次のような点が更新・強調されています。

### 1. 経営戦略との一体化の強化

DX戦略を独立した戦略としてではなく、経営戦略・事業戦略と一体で考えるべきという方向性がより明確に打ち出されています。

### 2. SX・GXとの接続

サステナビリティ・脱炭素といった社会課題への対応とDXを連動させる観点が追加されました。デジタル技術がサステナビリティ目標達成の手段として位置づけられています。

### 3. 人的資本・組織変革の重視

DX推進における人材育成・組織文化の変革が重視され、デジタル人材の確保・育成、リスキリングなどが取り組み事項として明示されています。

### 4. ステークホルダーへの情報開示

DXの取り組み状況を投資家・取引先・従業員などに向けて適切に開示することが求められます。Webサイトでの公表が要件となるため、社内文書だけでは対応できません。

## 中小企業に求められる対応

「コード対応」と聞くと身構えがちですが、中小企業に求められるのは大企業と同じレベルではありません。経済産業省「中堅・中小企業向けDX推進の手引き2025」でも、規模に応じた現実的な取り組みが想定されています。

具体的には次のような範囲が中小企業の標準的な対応イメージです。

- **経営ビジョンの言語化**: A4数ページで構わない
- **DX戦略の策定**: 自社のWebサイトに公表できる粒度で文書化
- **推進体制の明示**: 専任部署がなくても、経営層・現場・IT担当の役割を整理
- **指標の設定**: 売上・コスト・処理時間など測れるものから始める
- **公表**: Webサイト「お知らせ」「会社情報」内などに掲載

完璧を目指す必要はなく、**自社の身の丈に合った形で公表できているか**が判断ポイントです。

## 上場企業との対応範囲の違い

上場企業ではコーポレートガバナンス・コードや有価証券報告書での開示と整合させる必要があり、DXに関する情報開示の要求水準が高くなります。一方、非上場の中小企業はそこまでの開示義務はありません。

ただし、**取引先・採用市場・金融機関**といったステークホルダーが企業のデジタル対応状況を見る目線は厳しくなっており、自主的に開示することが信用に繋がる時代に入っています。中小企業も「公表することで得られる信用」を計算に入れて対応を検討する必要があります。

## DX認定との関係

デジタルガバナンス・コードに対応していることは、DX認定取得の前提条件でもあります。コード対応とDX認定取得は実質的にセットで考えるのが効率的です。

- まずコードの基本的事項に沿って自社の戦略・体制を整える
- 整備した内容を自社サイトに公表する
- その状態でDX認定に申請する

順序を踏むことで、形式的でない実態のある取り組みになります。

## 2026年4月運用開始の指標との関係

経済産業省は、デジタルガバナンス・コード3.0と整合する形で、新たなDX関連指標の運用を進めています。指標体系は時期によって更新されるため、最新の運用開始時期・対象範囲は経済産業省の公式ページで確認することが必須です。中小企業にとって重要なのは、**指標の細部を追いかけることではなく、自社の経営課題と連動した形でDX推進を進めること**であり、指標はその進捗を測る道具と捉えるのが適切です。

## 今のうちにやっておくべきこと

中小企業がコード3.0時代に備えて準備すべきことをまとめると次のようになります。

- **自社のDX戦略を1〜2ページにまとめる**: 何のために、何をやるのか
- **推進体制を文書化する**: 誰が責任を持つかを明確にする
- **進捗を測る指標を3つ決める**: 多すぎず、確実に取れるものに絞る
- **公表する場を決める**: Webサイトのどこに載せるか、更新頻度はどうするか
- **半年に一度見直す習慣をつける**: 一度作って終わりにしない

## DXは「続けられる仕組み」が本質

デジタルガバナンス・コードが繰り返し強調しているのは、DXは経営戦略と一体で継続的に推進すべき取り組みだという点です。一度きりのプロジェクトではなく、経営の中に組み込むこと——これがコード3.0時代の本質的なメッセージです。中小企業も、無理のない範囲で「続けられる仕組み」を作ることから始めるのが現実的です。
