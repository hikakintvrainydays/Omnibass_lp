# インボイス制度|2026年9月の20%特例終了で何が変わるか

2023年10月に施行されたインボイス制度(適格請求書等保存方式)では、免税事業者からの仕入れに係る経過措置として、仕入税額の一定割合を控除できる仕組みが設けられています。このうち「80%控除」の経過措置が2026年9月末で終了し、2026年10月以降は「50%控除」へと段階が下がる予定です。本記事では、国税庁の公式情報をもとに、特例終了の前後で何が変わるのかと、中小企業が今のうちに進めておきたい対応の方向性を整理します。具体的な適用日付や数値は最新の公式情報を要確認です。

## 経過措置の全体像

インボイス制度のもとでは、原則として、適格請求書発行事業者(登録事業者)が交付する適格請求書に基づく仕入れでなければ、仕入税額控除を受けられません。ただし、制度開始による影響を緩和するため、免税事業者など、適格請求書発行事業者以外からの仕入れについても、一定期間は仕入税額相当額の一部を控除できる経過措置が設けられています。

国税庁の特設サイトによれば、この経過措置は段階的に縮小される構造になっています。制度開始から一定期間は仕入税額相当額の80%、続く一定期間は50%が控除可能とされ、その後は経過措置が終了する予定です。各段階の境目となるのが、ちょうど2026年10月のタイミングと位置づけられています。具体的な適用期間や対象範囲は、必ず国税庁の最新公式情報を確認してください。

## 2026年9月までと10月以降の違い

2026年9月末までの期間においては、免税事業者などからの仕入れについても、適格請求書ではない請求書等に基づき、仕入税額相当額の80%相当を仕入税額控除に算入できる扱いとなっています。会計上は、仕入税額のうち20%相当が控除できない分として処理する必要がありますが、それでも全額控除不可とはなっていません。

2026年10月以降は、控除割合が50%へと引き下げられる段階に移行します。同じ取引内容・同じ金額で免税事業者から仕入れた場合でも、控除可能な仕入税額が減少することになり、買い手側の納税額に影響します。長期にわたって免税事業者と取引を続ける予定がある中小企業にとっては、税負担の構造が変わる重要な節目となります。

実際に控除割合を適用するためには、区分記載請求書等保存方式における請求書等の保存と、帳簿への一定事項の記載が必要です。記載事項や保存方法の詳細は、国税庁の公式情報を要確認です。

## 免税事業者との取引をどう考えるか

経過措置の段階的な縮小は、免税事業者との取引の見直しを促す動きとして受け止められがちですが、買い手側からの一方的な対応には独占禁止法や下請法の観点からの注意が必要です。公正取引委員会・財務省・中小企業庁などから示されてきた考え方では、登録の有無を理由に一方的に取引価格を引き下げることや、取引を打ち切ることは、優越的地位の濫用などの問題となり得るとされています。

対応の選択肢としては、(1) 取引先と消費税相当額の取扱いについて協議し、合意のうえで価格を見直す、(2) 取引先が登録するかどうかは取引先の判断であることを尊重しつつ、自社の負担増を見越して価格交渉や取引条件の見直しを行う、(3) 取引先のミックス(課税事業者・免税事業者の構成)を踏まえた仕入計画を立てるといった方法が考えられます。

いずれの場合も、書面ベースでのやり取りや合意の記録を残すことが重要です。具体的な交渉や契約条件の変更については、独占禁止法・下請法の解釈にかかわる論点もあるため、必要に応じて弁護士や税理士などの専門家に相談することが安全です。

## 中小企業が進めておきたい対応ステップ

2026年10月以降を見据えて、中小企業が進めておきたい対応ステップを整理します。

第一に、取引先一覧の棚卸しです。主要な仕入先・外注先について、適格請求書発行事業者かどうか、登録番号の有無、取引金額の規模を整理し、経過措置縮小の影響を受ける取引額を把握します。第二に、会計・経費精算システムの設定確認です。仕入区分(課税仕入・経過措置適用・対象外)の自動判定機能や、登録番号のマスタ管理機能が、2026年10月の控除割合変更に追随できるかをベンダーに確認します。

第三に、社内マニュアルと請求書受領時のチェックフローの整備です。請求書受領担当者が、登録番号の有無や記載事項の不備を一定の基準で確認できる仕組みを作っておくことで、後の経理処理がスムーズになります。第四に、価格・発注条件の見直しが必要かどうかの社内検討です。これは独禁法・下請法の論点を踏まえる必要があるため、検討プロセス自体を文書化しておくことが望ましいといえます。

## システム面で確認しておきたいポイント

会計システム・販売管理システム・経費精算システムなどでは、インボイス対応の機能アップデートが継続的に行われています。控除割合が80%から50%に変わるタイミングで、税区分や勘定科目の自動判定が正しく更新されるか、過去取引の集計や年度をまたぐ取引にどう対応するかは、システムごとに挙動が異なります。

また、電子取引データの保存(電子帳簿保存法の電子取引区分)とインボイス制度は、実務上は密接に関わります。電子請求書を受領した場合、その電子データの保存方法と、インボイス要件を満たすための記載事項確認は、同じフローのなかで処理されることが多いためです。両制度を同時に意識した運用ルールにしておくと、現場の負担を抑えられます。

## まとめ

インボイス制度の経過措置は段階的に縮小される設計となっており、2026年9月末で「80%控除」の段階が終了し、10月以降は「50%控除」の段階へ移行する予定です。中小企業にとっては、免税事業者からの仕入れに関わる税負担の構造が変化する重要な節目になります。取引先の棚卸し、会計システムの設定確認、社内マニュアルの整備を、できるだけ早いタイミングで進めておくことが望ましいでしょう。具体的な要件・適用日付は最新の公式情報を要確認のうえ、税務上・取引上の論点については税理士・弁護士などの専門家に相談しながら対応を進めてください。
