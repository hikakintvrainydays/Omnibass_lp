# リスキリング補助金|中小企業の人材投資に使える制度

人材育成は重要だと分かっていても、中小企業にとって研修費用や受講中の人件費負担は決して軽くありません。これを補うために国が用意している支援制度として、厚生労働省の「人材開発支援助成金」と、経済産業省が所管する「リスキリングを通じたキャリアアップ支援事業」があります。本稿では、中小企業が人材投資の財源として活用できるこれら制度の概要、対象、申請の流れを整理します。

## 公的支援を使う意義

人材育成は時間がかかり、費用対効果が見えにくいテーマです。経営判断として後回しになりがちですが、公的支援を活用すれば自社負担を抑えながら本格的な投資が可能になります。

「自社で負担できる範囲だけ実施する」発想ではなく、「制度を前提に投資計画を組み立てる」発想に切り替えることで、育成スピードを加速できます。とくにリスキリング(働き手の学び直し)領域は政策的な後押しが厚く、中小企業も使いやすい仕組みが整備されています。

## 人材開発支援助成金とは

人材開発支援助成金は、厚生労働省が事業主向けに提供する助成金制度です。労働者に対して職務に関連する専門的な知識・技能の習得を目的とした職業訓練を計画・実施した事業主に対して、訓練経費や訓練期間中の賃金の一部を助成します。

人材開発支援助成金にはいくつかのコースがあり、リスキリングや特定分野の能力開発を支援する内容も含まれます。詳細なコース構成や助成額・助成率は厚生労働省の公式ページで継続的に更新されているため、申請を検討する際は最新版を必ず確認してください。

中小企業にとって特に注目すべきポイントは以下です。

- 訓練経費だけでなく、訓練期間中の賃金も助成対象になりうる
- OFF-JT(集合研修・eラーニング)とOJTを組み合わせた訓練計画が可能
- 自社で実施する訓練も外部委託する訓練も対象になりうる

## リスキリングを通じたキャリアアップ支援事業

経済産業省が所管する「リスキリングを通じたキャリアアップ支援事業」は、在職者個人がキャリアアップを目的としてリスキリングに取り組む際に、伴走支援・学習費用の補助・転職支援などを一体的に提供するスキームです。事業主への直接の助成というより、働き手個人を主体とした支援設計になっている点が特徴です。

公式サイト(reskill-career.smbiz.go.jp)では、提携するキャリアコーチング事業者・教育訓練事業者・転職支援事業者の一覧、対象者要件、補助の仕組みが公開されています。中小企業の経営者・人事担当者がこの制度を社員に案内する場合は、最新の事業要綱を確認した上で進める必要があります。

事業主の立場から見ると、社員が自発的にリスキリングへ取り組む動きを後押しできる制度として位置付けられます。社員のキャリア自律を促しつつ、結果として社内のスキル底上げにつなげる狙いを持つ企業に向いています。

## 補助・助成の対象になりうる訓練の例

両制度とも、対象となる訓練・学習の範囲は要綱で具体化されています。一般論として、中小企業のDX推進と関係が深い領域では次のようなテーマが対象となりえます。

- データ分析・データ活用の研修
- クラウドサービス活用に関する研修
- 業務システム・SaaSの操作研修
- 情報セキュリティ研修
- AI・生成AIの業務活用に関する研修
- プロジェクトマネジメント研修

ただし、対象となるかは制度ごと・コースごとに細かく定められており、年度ごとに見直されます。「DXに関連していそう」だけでなく、要綱・Q&Aで個別に確認することが必須です。

## 申請の基本的な流れ

人材開発支援助成金の申請は、おおまかに次の流れで進みます。

### ステップ1:訓練計画を立てる

訓練の対象者、内容、期間、実施方法、費用、賃金の扱いを整理します。OFF-JT/OJTの構成、外部委託の有無も明示します。

### ステップ2:訓練実施計画届の提出

訓練を始める前に、所定の様式で計画届を労働局へ提出します。事前提出が原則であり、訓練開始後の届出は対象外となるケースが多い点に注意が必要です。

### ステップ3:訓練の実施

計画通りに訓練を実施し、出席記録・受講記録・賃金台帳などの実施記録を整えます。

### ステップ4:支給申請

訓練終了後、所定の期間内に支給申請書と添付書類を提出します。書類不備や期限切れで支給対象外となるケースもあるため、社内ルール化することが望まれます。

### ステップ5:支給決定

審査を経て支給額が決定されます。支給までには時間がかかるため、キャッシュフロー上は立替前提で計画する必要があります。

リスキリング支援事業については、個人申請型のスキームのため、社員が直接事業者を通じて手続きする形になります。事業主は情報提供と受講時間の確保で側面支援するのが基本です。

## 申請時の注意点

中小企業が公的支援を活用する際、つまずきがちなポイントを整理します。

- **事前申請が原則**: 訓練を先に始めてしまうと対象外になる場合がある
- **書類の整合性**: 計画届と実施記録の内容が食い違うと支給されない
- **対象労働者の要件**: 雇用保険被保険者であることなど、対象者の要件が定められている
- **要綱の年度更新**: 制度内容・助成額は毎年見直されるため、最新版を確認する
- **就業規則との整合**: 訓練に関する規定や賃金支給ルールが就業規則に整合している必要がある

不安な場合は、所轄の労働局やよろず支援拠点、社会保険労務士などの専門家に相談しながら進めると確実です。

## 制度活用と人材戦略の接続

公的支援はあくまで財源の一つであり、これに依存して育成計画を組むのは本末転倒です。次の順序で考えるのが健全です。

1. 自社の事業戦略から育成すべき人材像を逆算する
2. それに必要な訓練・学習を年間プランに落とし込む
3. その訓練を支援対象にできる制度を探す
4. 申請可能な部分を申請し、不足分は自社負担で補う

中長期の人材戦略があってこそ、補助金は「効率化の手段」として機能します。

## まとめ

人材開発支援助成金は、訓練経費や訓練期間中の賃金の一部を助成する事業主向けの定番制度であり、リスキリングを通じたキャリアアップ支援事業は、在職者個人のキャリアアップ・学び直しを支援する経済産業省の事業です。両者は性格が異なるものの、中小企業のDX人材育成にとっては有力な財源・後押しとなります。要綱は年度ごとに更新されるため、必ず最新の公式情報を確認し、自社の人材戦略と接続して活用することをおすすめします。
