# 営業資料・提案書作成にChatGPTを使う|具体的な手順

営業担当者にとって、提案書や営業資料の作成は「成果を生む仕事」と「時間が取られる雑務」が混在しがちな業務です。中小企業では一人の営業が提案・契約・フォローまで担当することも多く、資料作成の効率化は売上機会に直結します。

ChatGPTを業務文書作成の補助として使う事例は、OpenAIが公開しているUse Casesでも継続的に紹介されています。本記事では、営業資料・提案書作成にChatGPTを活用する具体的な手順と、機密情報の扱い方、品質チェックまでを整理します。

## 提案書作成の典型工程

提案書を作る作業を分解すると、おおよそ以下のステップになります。

1. ヒアリング内容と顧客課題の整理
2. 提案の骨格(構成案)の作成
3. 各章の本文作成
4. 図表、ビジュアル要素の整備
5. 価格や見積条件の検討
6. 全体レビューと仕上げ

このうち、ChatGPTで効率化しやすいのは1〜3、および6の文章レビューです。価格設定や図表ビジュアル、最終判断は人間の役割として残ります。

## 効率化できるパート1:ヒアリング内容の整理

商談メモ、議事録、メールスレッドなど、断片的な情報からポイントを整理する作業はChatGPTが得意です。

プロンプトの例:
```
以下は顧客とのヒアリング議事録です。
これをもとに、顧客が抱えている課題と、解決したい優先順位を3点に整理してください。
出力形式:
- 課題1:[内容] / 優先度:高/中/低
- 課題2:...
- 課題3:...

[議事録テキスト]
```

人間の頭で整理する時間を圧縮し、すぐに提案の骨格作りに移れます。

## 効率化できるパート2:提案構成案の作成

整理された顧客課題に対して、どのような流れで提案するかの構成案をChatGPTに出させます。

プロンプトの例:
```
顧客の課題は以下のとおりです。
[整理された課題]

これに対する提案書の章構成案を、A案・B案・C案で3パターン提示してください。
それぞれ章タイトルと、各章で伝えるべき主旨を1行で添えてください。
```

複数案を出すことで、人間が比較検討してベストな構成を選べます。「自分一人で考えるより視点が広がる」点が活用の本質です。

## 効率化できるパート3:本文の下書き

構成が決まったら、章ごとの本文ドラフトをChatGPTに作らせます。

プロンプトの例:
```
以下の章の本文を作成してください。

章タイトル:御社の業務課題と現状分析
読み手:中堅製造業の経営者
文字数:400字程度
含める要素:
- 業界全体の課題傾向
- 具体的な業務上の影響
- 解決の方向性の示唆
文体:です・ます調、専門用語は最小限

参考情報:
[整理された課題内容]
```

本文の下書きが手元にある状態から始まると、ゼロから書く時の心理的ハードルが大きく下がり、内容の磨き込みに集中できます。

## 機密情報の取り扱い

営業資料の作成では、顧客情報、価格情報、未公開の戦略情報など、機密性の高い情報を扱う場面が多くあります。ChatGPTに入力する前に、必ず以下を確認しましょう。

### 利用プランの確認
法人向けプラン(ChatGPT Team、Enterprise、Microsoft 365 Copilotなど)を使い、入力データが学習に利用されない設定になっていることを確認します。詳細はOpenAIなど各社の公式ページで最新仕様を確認してください。

### 入力前の情報マスキング
顧客社名、担当者名、具体的な金額などは「A社」「担当者X」「○○○万円」など仮の表現に置き換えてからAIに渡し、最終出力で実情報に差し替える運用が安全です。

### 社内ガイドライン遵守
入力可能な情報レベルは、会社のガイドラインで定められた範囲を厳守します。判断に迷うものは入力しない原則が基本です。

## 品質チェックの手順

ChatGPTの出力をそのまま提案書として使うと、事実誤認や不適切な表現が紛れ込むリスクがあります。以下の手順で品質を確保しましょう。

### 1. 事実関係の確認
業界統計、製品仕様、法令などの数値・固有情報は必ず一次情報で確認します。AIの出力は確率的な生成のため、もっともらしい誤情報が混在する場合があります。

### 2. 固有名詞のチェック
顧客社名、商品名、人名などの誤りがないかを念入りに確認。AIが類似名称を勝手に生成するケースもあるため、原本との突合が必要です。

### 3. 表現の統一性
社内で使う標準的な表現、敬称、用語に揃っているかを確認。AIは同じ概念に複数の表現を使うことがあるため、最終的に表記を統一します。

### 4. 顧客視点の最終レビュー
読み手の立場に立って、「この提案で伝わるか」「説得力があるか」を確認。AIは論理的な文章は作れても、顧客個別の事情に踏み込んだ説得力は人間が加える必要があります。

### 5. ダブルチェック
重要な提案では、もう一人の同僚や上司にレビューを依頼。AI生成物への過信を防ぐ意味でも、人間の複数視点が有効です。

## ChatGPT活用のコツ

営業資料作成でChatGPTを使い続けると、自分なりのプロンプトテンプレートが蓄積されていきます。これを社内で共有することで、組織全体の営業資料の品質と作成スピードが底上げされます。

おすすめの取り組み:
- **テンプレート集**:業種別、提案書タイプ別のプロンプトテンプレートを整備
- **成功事例の共有**:成約に至った提案書とそこで使ったプロンプトをセットで共有
- **ナレッジの定期更新**:月次や四半期ごとに、有効だったテンプレートを洗練

ChatGPTは「ゼロから生み出す」道具ではなく、「書く時間を縮めて、考える時間を増やす」道具と捉えると、営業現場での価値が明確になります。提案の中身を考える本質的な時間を確保することが、最終的な成約率向上につながります。
