# YamatoDX DXコラム 100本 企画書

## 全体方針

- **目的**: ヤマトDX (digital-yamato-dx.jp) のSEO向上、中小企業DX領域の検索流入獲得
- **公開先**: WordPress (cms.biwako-omnibass.com) の `dx-columns` CPT に `status=publish` で一気投稿
- **記事ボリューム**: 1本 2,000〜3,000文字、見出し5〜7個、出典リンク必須
- **絶対NG**:
  - 架空の案件・架空事例の捏造
  - 実在しない情報源・URLの記載
  - ヤマトDXの信頼を毀損する内容(具体企業名の批判、未確認の数値断定など)
  - 同一サムネ画像の複数本での使い回し
- **トーン**: 中立的・実務的・読者目線。中小企業の経営者/現場責任者が読んで判断材料にできるレベル。
- **CTA**: 強い誘導は入れない。自然に文脈で触れる程度。SEO最優先。

## 出典の使い方ルール

- **公的機関の一次情報** (IPA / 経産省 / 中小企業庁 / 総務省 / 滋賀県等): 数値・制度の根拠として最優先で引用
- **ベンダー公式の公開導入事例**: 「kintoneが公開している事例によると〜」のように "公開事例ベース" として引用、企業名は公式ページに出ているものに限る
- **一般論・ベストプラクティス**: 業種別・業務別の汎用的な指針として記述、特定企業を主語にしない
- **「ヤマトDXの実績」と読み取れる書き方は禁止** (架空案件と区別がつかなくなるため)

## SEO対応 (記事内で実装する要素)

- titleタグ: `{タイトル} | YamatoDX DXコラム` (60文字以内)
- meta description: 記事の要約 120〜140字
- 見出し: H1は1つだけ、H2/H3で階層化
- 内部リンク: 関連する他コラム3〜5本へのリンク (related-articles.js が自動生成するが、本文中にも自然に1〜2本)
- 外部リンク: 一次出典には `target="_blank" rel="noopener"` で必ずリンク
- 画像: heroにサムネ1枚、本文中に追加画像は基本入れない (関連性が薄いと逆効果のため)
- 構造化データ: seo.js が JSON-LD (Article) を自動付与
- スラッグ: `dx001` 〜 `dx100` (短く、ID固定)
