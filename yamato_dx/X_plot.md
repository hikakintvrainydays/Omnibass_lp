# 🐦 X（Twitter）運用計画（Takeuchi Yamato）

## 🎯 目的
Xでは、以下3つの目的を達成する。

1. **認知の拡大（若手×スピード×多領域の印象形成）**  
2. **ブランド定着（技術・実績・挑戦の可視化）**  
3. **LP（ポートフォリオ）やGitHubへの導線 → 問い合わせ獲得**

---

# ⭐ 運用コンセプト
**若手 × スピード × 多領域 × 現場解決**  
を世界観として統一して発信する。

``若いのに強い / 速い / 多領域を横断 / 行動している人``  
という印象を定着させる。

---

# 🧩 投稿ジャンル（7ジャンル構成）
すべて組み合わせてOK。  
あなたのブランドに最も適したバランス。

## 1. 開発ログ（最重要）
- 今日作ったもの、途中経過、動く画面  
- 「動く若手」という最大の武器になる

## 2. 技術Tips（AI / 自動化 / DX）
- GAS / Python / Django / LLM など  
- 専門性の証明になる

## 3. 自動化のビフォーアフター
- 「30分 → 3分になりました」など効果を明確に  
- 店舗DX・中小企業に刺さる

## 4. 実績の断片公開
- バス需要予測（新聞掲載）  
- 選挙データ  
- 店舗DX  
- Djangoツール

## 5. 成長ログ（学習・制作記録）
- あなたの“成長速度”がブランドになる

## 6. 挑戦ログ（スピード・熱量）
- 「今日3時間で〇〇を作った」  
- 「新しいAPI挑戦」  
- あなたの性格そのものを伝える

## 7. ポートフォリオ更新情報
- 「LP更新しました」  
- 「実績追加しました」  
- 導線の中心

---

# 📊 投稿比率（黄金比）


30%：開発ログ
20%：自動化ビフォーアフター
15%：挑戦ログ
15%：技術Tips
10%：実績断片
5%：成長ログ
5%：LP更新


この比率で“技術 × スピード × 成長 × 実務力”が最大化される。

# 🔁 投稿頻度
- **週2〜3投稿（無理なく継続）**  
- 1投稿は短文でOK（60〜120文字）  
- 画像・動画・GIFは可能ならつけると強い

---

# 🎯 KPI（3階層モデル）

## ■ レベル1：活動KPI（努力で達成可能）
- 投稿：週2〜3  
- 開発ログ：月8〜10  
- GitHub更新：月4  
- LP更新：月1〜2  

## ■ レベル2：ブランドKPI（印象形成）
- プロフィールクリック数  
- LPクリック数  
- GitHubクリック数  
- 投稿保存数（Tips系）  
- 投稿シェア数  

## ■ レベル3：ビジネスKPI（最重要）
- SNS → LP流入数  
- SNS → 問い合わせ数  
- 無料相談数  
- 月ごとのSNS経由売上  

---

# 🔥 導線設計（最重要セクション）

## ■ SNS → LP（ポートフォリオ）
- 投稿の末尾にLPリンク  
- 週1回LP更新報告  
- サービス紹介をLPに集約

## ■ SNS → GitHub
- 技術Tips・開発ログで自然にGitHubリンク  
- 「更新しました」「デモ追加しました」など

## ■ LP → GitHub／SNS
- LP内にGitHub・Xへのリンク  
- 技術力の裏付けとして配置

## ■ SNS → 問い合わせ（CV）
- 「30分無料相談」  
- LINE・Gmailの導線を固定ツイに載せる  

---

# 🧪 投稿テンプレ（ジャンル別）
（必要なら後で詳しく展開します）

### ■ 技術Tips
- GAS × Pythonで〇〇  
- Djangoで管理画面を拡張  
- LLM評価のポイント  

### ■ 挑戦ログ
- 「今日は〇〇のAPIを試した」  
- 「新ツールを最速で試作」
